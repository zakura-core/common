## zakura-primitives

### Changed

- Wallet builders use a 150-block default expiry and the ZIP 223 shielded action
  limits from the configured NU7.1 target height
  ([#755](https://github.com/zakura-core/common/pull/755)).

## zakura-protocol

### Changed

- ZIP 318 scheduling, anchor boundaries and rolling expiry support 20-second
  blocks. Use `BlockSpacing::target_spacing_seconds` or the duration methods in
  place of `blocks_per_reference_block`, whose integer result cannot represent
  the new spacing ratio ([#755](https://github.com/zakura-core/common/pull/755)).
