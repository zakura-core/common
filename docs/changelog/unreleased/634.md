## zakura-zcash-script

### Added

- Added the complete `zcash_script 0.6.0` implementation as the
  `zakura-zcash-script` package, retaining the `zcash_script` library target,
  the script, interpreter, solver, descriptor, and signature APIs, features,
  and no-std support. The package keeps upstream's Apache-2.0 license and
  inherits Common's edition 2024 and MSRV
  ([#634](https://github.com/zakura-core/common/pull/634)).

## zakura-transparent

### Changed

- Changed the script types in public signatures, such as `address::Script`
  and `TransparentAddress::script`, from the `zcash_script` package to
  `zakura-zcash-script`. Import paths are unchanged, but upstream
  `zcash_script` types cannot be mixed with the fork's
  ([#634](https://github.com/zakura-core/common/pull/634)).
