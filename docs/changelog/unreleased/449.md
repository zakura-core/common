This PR only changes private quotient-evaluator planning. It reuses existing
cache-slot lifetime gaps for repeated add/sub-only subexpressions, removing
163,840 row additions and at least 2 MiB of logical field-word traffic from a
one-Action Ironwood proof, or 704,512 additions and 8.5 MiB from a four-Action
proof. Physical evaluator workspace is unchanged, retained plan payloads get
slightly smaller, and proof bytes and public and `pub(crate)` APIs are
unchanged.
