## zakura-reddsa

### Added

- Added `From<VerificationKey<sapling::SpendAuth>> for jubjub::AffinePoint`
  to normalize a stored spend authorization point without decoding its bytes
  ([#677](https://github.com/zakura-core/common/pull/677)).

## zakura-redjubjub

### Added

- Added `From<VerificationKey<SpendAuth>> for jubjub::AffinePoint` to expose
  a spend authorization key's normalized point without decoding it again
  ([#677](https://github.com/zakura-core/common/pull/677)).
- Added `batch::Item::from_spendauth_key` to retain an existing spend key
  through batch and fallback signature verification
  ([#677](https://github.com/zakura-core/common/pull/677)).

## zakura-sapling-crypto

### Changed

- Spend preparation reuses the stored randomized verification-key point for
  affine coordinates and the existing small-order check, and signature
  batching retains the key instead of decoding it again
  ([#677](https://github.com/zakura-core/common/pull/677)).
