## zakura-zcash-script

### Added

- Added `OP_CHECKSIGADD` to post-quantum scripts, with a signature-check budget
  (`pq::CheckBudget`) that `pq::eval_script` now takes: each check given a
  non-empty signature costs one signature's size of the input, and a spend whose
  checks cost more fails before the excess checks run. Added
  `pq::signature_check_count` for counting checks in a post-quantum script,
  `pq::SpendingInput::input_bytes` for the size the budget is taken from, and
  the errors `PqMultisig`, `PqCheckBudget`, `PqNullFail` and `PqMinimalIf`
  ([#750](https://github.com/zakura-core/common/pull/750)).

### Changed

- Post-quantum scripts reject `OP_CHECKMULTISIG` and `OP_CHECKMULTISIGVERIFY`
  wherever they appear, fail on any non-empty signature that does not verify,
  and require minimally encoded numbers and an empty or `0x01` argument to `IF`
  and `NOTIF` ([#750](https://github.com/zakura-core/common/pull/750)).

## zakura-transparent

### Added

- Added `pq::ParameterSet::check_budget`
  ([#750](https://github.com/zakura-core/common/pull/750)).

### Changed

- Post-quantum spend verification budgets signature checks by the size of the
  whole serialized input, and `pq::script::verify_script` takes that size.
  `PqSpend::sig_op_count` takes no argument and returns the smaller of the
  script's checking opcodes and the checks its input pays for
  ([#750](https://github.com/zakura-core/common/pull/750)).
