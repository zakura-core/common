## zakura-sapling-crypto

### Added

- Added the opt-in `fused-pedersen` feature, which caches fused chunk-block
  lookup tables (about 6.2 MiB) to speed up non-circuit Pedersen hashing. The
  default remains the original 8-bit exp-window tables
  ([#81](https://github.com/zakura-core/common/pull/81)).
