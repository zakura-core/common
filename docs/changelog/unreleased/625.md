## zakura-orchard

### Added

- Added the `sensei-bench` feature, exposing `circuit::ProofBatch`
  (signature-free batch proof verification) and unstable worker controls for
  the external `scripts/sensei-bench` backend-comparison driver. Not for
  production use
  ([#625](https://github.com/zakura-core/common/pull/625)).

### Changed

- The `portable` feature now disables all handwritten assembly in the selected
  backend on every platform, including AArch64 assembly enabled by
  target-specific dependencies
  ([#625](https://github.com/zakura-core/common/pull/625)).

## zakura-pasta-curves

### Changed

- The `portable` feature now disables all handwritten assembly, including an
  explicitly enabled `aarch64-asm`, so one feature reliably selects the
  portable arithmetic on every platform
  ([#625](https://github.com/zakura-core/common/pull/625)).
