## zakura-halo2-proofs

### Changed

- Replaced the optional `zakura-halo2-legacy-pdqsort` dependency with an
  internal copy of the same sort; the `floor-planner-v1-legacy-pdqsort`
  feature keeps its name and produces the same region order, so circuit
  layouts and verifying keys are unchanged
  ([#610](https://github.com/zakura-core/common/pull/610)).

### Removed

- Removed the implicit `halo2_legacy_pdqsort` feature that Cargo created for
  the former optional dependency; enable `floor-planner-v1-legacy-pdqsort`
  instead ([#610](https://github.com/zakura-core/common/pull/610)).
