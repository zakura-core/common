## zakura-protocol

### Added

- Added the `Zcash/WOTS/node/v1` domain constant for the Merkle nodes that
  commit to one account step's spare keys
  ([#643](https://github.com/zakura-core/common/pull/643)).

## zakura-transparent

### Changed

- Replaced the experimental one-time WOTS redeem script with post-quantum
  accounts: one fixed P2SH address whose spending key changes on every spend,
  tracked by a control output. Adds the account and control-output templates,
  four-spare key sets, authorizations, prototype key derivation from a seed,
  and `check_accounts`, the consensus rules over raw scripts
  ([#643](https://github.com/zakura-core/common/pull/643)).

## zakura-zcash-script

### Removed

- Removed the experimental `CHECKWOTS` instruction, its flag, its checker
  method and the `experimental-pq-transparent` feature; account inputs are now
  validated outside the interpreter
  ([#643](https://github.com/zakura-core/common/pull/643)).
