## zakura-orchard

### Changed

- Gate indexed ZIP 32 address generation and diversifier-index recovery behind
  the default-enabled `zip32-addresses` feature. Consumers disabling default
  features must opt in to retain these APIs; direct address construction and
  note decryption remain available without FF1
  ([#552](https://github.com/zakura-core/common/pull/552)).

## zakura-sapling-crypto

### Changed

- Gate indexed ZIP 32 address generation and diversifier-index recovery behind
  the default-enabled `zip32-addresses` feature. Consumers disabling default
  features must opt in to retain these APIs; key derivation, direct address
  construction, and note decryption remain available without FF1
  ([#552](https://github.com/zakura-core/common/pull/552)).

## zakura-keys

### Changed

- Add the default-enabled `zip32-addresses` feature for Unified Address
  generation, diversifier-index recovery, gap-address generation, and address
  test generators. Consumers disabling default features must opt in to retain
  these APIs
  ([#552](https://github.com/zakura-core/common/pull/552)).
