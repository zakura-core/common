## zakura-protocol

### Added

- Added `encoding::Vector::read_bytes` and `encoding::Array::read_bytes`,
  which decode byte vectors in bulk with the same results and errors as
  per-byte `Vector::read` and `Array::read`
  ([#631](https://github.com/zakura-core/common/pull/631)).

## zakura-transparent

### Changed

- Sped up `Script::read` by reading script bytes in bulk
  ([#631](https://github.com/zakura-core/common/pull/631)).

## zakura-primitives

### Changed

- Sped up transaction and block header parsing by reading Orchard-family
  proof bytes and Equihash solutions in bulk
  ([#631](https://github.com/zakura-core/common/pull/631)).
