## zakura-bellman

### Changed

- Sped up Groth16 batch verification by up to about 2.4x. One proof in
  each batch pairing equation now has weight 1, and every other proof gets
  an independent random nonzero 128-bit weight applied with variable-time
  arithmetic, in place of a full-width random scalar (or, in the multicore
  verifier, powers of one). A batch containing an invalid proof is accepted
  with probability at most 1 / (2^128 - 1), independent of the batch size
  ([#667](https://github.com/zakura-core/common/pull/667)).

## zakura-reddsa

### Changed

- Sped up RedDSA batch verification by giving one signature in each batch
  weight 1 instead of a random weight
  ([#667](https://github.com/zakura-core/common/pull/667)).
