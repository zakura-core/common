## zakura-halo2-proofs

### Changed

- At `k = 11`, explicit polynomial commitment preparation now retains 1 MiB
  of normalized GLV windows for the first IPA generator fold. On Apple M4,
  this saved about
  0.27 ms in isolated fold measurements and 0.20 ms in a 100-pair first-proof
  benchmark. The fold occurs once per proof, independent of the number of
  Actions, and adds about 1.7--1.85 ms to explicit preparation
  ([#323](https://github.com/zakura-core/common/pull/323)).
