## zakura-protocol

### Changed

- Renamed the key-set node domain constant to `PQ_KEY_SET_NODE_DOMAIN`, with
  the scheme-neutral value `Zcash/PQ/node/v1`
  ([#644](https://github.com/zakura-core/common/pull/644)).

## zakura-transparent

### Changed

- Made the experimental post-quantum account signature scheme pluggable: the
  account rules use it only through the new `SignatureScheme` trait, and
  `pq::Scheme` names the one in use, currently WOTS+. Renamed the `wots`
  module to `pq`, `WotsInput` to `AccountInput` and
  `AccountCheck::wots_inputs` to `account_inputs`; replaced
  `WOTS_SIGOP_COST` with `AccountCheck::sigops`. Authorizations now carry one
  scheme witness in 512-byte pushes, and the master key label changed
  ([#644](https://github.com/zakura-core/common/pull/644)).
