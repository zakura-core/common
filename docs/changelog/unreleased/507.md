## zakura-pasta-curves

### Added

- Exposed `arithmetic::try_batch_from_bytes8` for checked eight-lane affine
  decoding on supported Pasta curves and CPUs. Unsupported configurations
  return `None` without decoding and retain scalar behavior
  ([#507](https://github.com/zakura-core/common/pull/507)).

### Changed

- Accelerated variable-time batch affine reduction with persistent eight-lane
  IFMA scratch on supported x86-64 CPUs when `glv` and `x86_64-asm` are enabled,
  retaining the scalar fallback. The packed reducer uses additional temporary
  scratch
  ([#507](https://github.com/zakura-core/common/pull/507)).

## zakura-halo2-proofs

### Changed

- Batched point decoding in the owned-proof batch verifier while preserving
  transcript read order and malformed-proof rejection
  ([#507](https://github.com/zakura-core/common/pull/507)).
