## zakura-pasta-curves

### Added

- `arithmetic::CoefficientProducts`, implemented for `Fp` and `Fq`: sums a
  batch of inner-product-argument challenge-product coefficient vectors,
  with a blocked AVX2 kernel on x86-64 builds that enable it
  ([#714](https://github.com/zakura-core/common/pull/714)).

## zakura-halo2-proofs

### Changed

- Batch verification sums the proofs' IPA generator coefficients in one
  pass instead of building a coefficient vector per proof, about halving
  that step's cost on AVX2 builds
  ([#714](https://github.com/zakura-core/common/pull/714)).
