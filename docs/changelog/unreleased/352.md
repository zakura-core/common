## zakura-halo2-proofs

### Fixed

- Fixed `poly::multiopen::create_proof` panicking on query polynomials with
  fewer than `params.n` coefficients; they are once again zero-extended as in
  1.0.0 ([#352](https://github.com/zakura-core/common/pull/352)).
- Fixed `Layouter::assign_table` closures not being invoked when proving with
  a cached `V1` floor plan, which silently suppressed their errors and side
  effects; they now run on every synthesis as in 1.0.0, reverting the
  performance change in [#334](https://github.com/zakura-core/common/pull/334)
  ([#352](https://github.com/zakura-core/common/pull/352)).
