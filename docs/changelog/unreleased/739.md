## zakura-primitives

### Added

- Added serialized-size constants for estimating a transaction's size before
  building it: `transaction::components::sapling::{SPEND_DESCRIPTION_SIZE,
  OUTPUT_DESCRIPTION_SIZE, BUNDLE_OVERHEAD}`,
  `transaction::components::orchard::{SPEND_AUTH_SIG_SIZE, BUNDLE_OVERHEAD}`,
  and `transaction::fees::zip317::{MAX_TRANSPARENT_INPUT_SIZE,
  TRANSPARENT_BUNDLE_OVERHEAD, TX_HEADER_SIZE}`
  ([#739](https://github.com/zakura-core/common/pull/739)).
- Made `transaction::components::sapling::testing::arb_bundle` public behind
  the `test-dependencies` feature
  ([#739](https://github.com/zakura-core/common/pull/739)).
