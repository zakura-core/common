Factor repeated first-row terms out of permuted Sinsemilla input commitments.
For sorted inputs, cached Lagrange suffix sums replace roughly 1,050 individual
base additions per lookup with one point subtraction. On an Apple M4 with ten
workers, this reduced lookup-permutation preparation by about 45 us for one
Action and 128 us for four Actions without changing proof bytes or retained
proving-key memory.
