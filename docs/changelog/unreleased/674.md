## zakura-orchard

### Changed

- The legacy backend now uses cached variable-time GLV multiplication for
  blinded value commitments and nullifiers. These wallet operations provide
  no constant-time guarantee for secret inputs
  ([#674](https://github.com/zakura-core/common/pull/674)).

## zakura-reddsa

### Changed

- The `pallas-pasta` backend now uses prepared variable-time GLV multiplication
  for RedPallas signing, key derivation, and key randomization, and one-shot
  GLV for variable-base verification without `alloc`. Signing and key
  operations may leak information about secret scalars through timing
  ([#674](https://github.com/zakura-core/common/pull/674)).

## zakura-halo2-gadgets

### Changed

- Fixed-base window table generation now reuses variable-time WNAF
  multiplication tables
  ([#674](https://github.com/zakura-core/common/pull/674)).
