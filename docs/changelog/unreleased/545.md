## zakura-note-encryption

### Changed

- Updated the ChaCha20/Poly1305 backend to share ChaCha20 0.10 with Rand,
  preserving key zeroization, ciphertext formats, and public interfaces
  ([#545](https://github.com/zakura-core/common/pull/545)).

## zakura-transparent

### Changed

- Updated to stable `bip32` 0.6, `secp256k1` 0.33, and `zcash_script` 0.6 as
  required by the cipher backend migration. `TransparentSignatureContext` no
  longer has lifetime/type parameters; `prepare_transparent_signatures` and
  PCZT input signing/signature methods no longer accept a secp256k1 context
  ([#545](https://github.com/zakura-core/common/pull/545)).

## zakura-keys

### Changed

- Updated transparent key dependency types to stable `bip32` 0.6 and
  `secp256k1` 0.33. Removed `Key::pubkey_with_context` and
  `Key::der_encode_with_context`; use `Key::pubkey` and `Key::der_encode`
  ([#545](https://github.com/zakura-core/common/pull/545)).

## zakura-primitives

### Changed

- Updated transparent dependency types to `secp256k1` 0.33 and `zcash_script`
  0.6, removing obsolete prerelease `block-buffer` and `crypto-common` pins
  ([#545](https://github.com/zakura-core/common/pull/545)).
