## zakura-halo2-proofs

### Changed

- Prepared polynomial commitment opening proofs now reuse the retained
  coefficient SRS table for both multiexponentiations in the first IPA round.
  Paired first-proof measurements improved one-action Orchard proving by about
  0.20 ms (0.33%) at ten threads on Apple M4 and 0.71 ms (0.57%) at six
  threads on x86_64 Linux, with no additional retained memory
  ([#313](https://github.com/zakura-core/common/pull/313)).
