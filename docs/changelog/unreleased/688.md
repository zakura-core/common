## zakura-pasta-curves

### Added

- Added `arithmetic::best_multiexp_vartime` and
  `arithmetic::best_multiexp_vartime_with_threads`, a variable-time
  multiscalar multiplication that uses the GLV backends where they are
  selected and a Signed-Booth bucket method otherwise, and
  `CurveExt::try_multiexp_vartime_with_threads` to plan the GLV backends for
  a capped number of workers
  ([#688](https://github.com/zakura-core/common/pull/688)).

## zakura-halo2-proofs

### Changed

- `arithmetic::best_multiexp` forwards to
  `pasta_curves::arithmetic::best_multiexp_vartime`. Its parallel
  Signed-Booth path combines window sums serially, cutting its doubling work
  ([#688](https://github.com/zakura-core/common/pull/688)).

## zakura-reddsa

### Added

- Added a `multicore` feature that lets RedPallas batch verification use the
  Rayon thread pool
  ([#688](https://github.com/zakura-core/common/pull/688)).

### Changed

- RedPallas batch verification evaluates its multiscalar multiplication with
  pasta's shared MSM instead of a serial wNAF, making Orchard-sized batches
  faster ([#688](https://github.com/zakura-core/common/pull/688)).

## zakura-orchard-legacy

### Changed

- The `multicore` feature also enables `zakura-reddsa/multicore`
  ([#688](https://github.com/zakura-core/common/pull/688)).
