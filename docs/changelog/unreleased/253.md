## zakura-halo2-proofs

### Changed

- Proof generation now overlaps independent permutation and lookup
  grand-product preparation. This reduced measured one- and four-action
  latency on ten-core Apple silicon and one-action latency on six-thread Linux,
  but increased six-thread Linux four-action latency by about 0.3-0.4%; no
  target- or worker-specific heuristic is applied. Successful proof bytes are
  unchanged. A custom transcript failure while writing a permutation
  commitment may now occur after more prover randomness has been consumed
  ([#253](https://github.com/zakura-core/common/pull/253)).
