## zakura-transparent

### Changed

- Migrated to `bip32 0.6`, `secp256k1 0.33`, and `zcash_script 0.6`
  ([#538](https://github.com/zakura-core/common/pull/538)).
- `zcash_transparent::builder::TransparentSignatureContext` no longer has
  lifetime or type parameters, and
  `zcash_transparent::bundle::Bundle<Unauthorized>::prepare_transparent_signatures`
  no longer takes a `secp256k1::Secp256k1` context argument
  ([#538](https://github.com/zakura-core/common/pull/538)).
- `zcash_transparent::pczt::Input::{sign, append_signature}` no longer take a
  `secp256k1::Secp256k1` context argument
  ([#538](https://github.com/zakura-core/common/pull/538)).

## zakura-keys

### Changed

- Migrated to `bip32 0.6`, `secp256k1 0.33`, and `zcash_script 0.6`
  ([#538](https://github.com/zakura-core/common/pull/538)).

### Removed

- Removed `zcash_keys::keys::transparent::Key::{pubkey_with_context,
  der_encode_with_context}`; use `Key::pubkey` and `Key::der_encode` instead
  ([#538](https://github.com/zakura-core/common/pull/538)).

## zakura-primitives

### Changed

- Migrated to `secp256k1 0.33` and `zcash_script 0.6`
  ([#538](https://github.com/zakura-core/common/pull/538)).
