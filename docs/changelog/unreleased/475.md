Reuse quotient-evaluator fold buffers across chunks instead of allocating and
initializing new domain slices for every fold. On x86-64 Linux with six
workers, evaluator execution improved by 0.164 ms for one-Action proofs and
0.287 ms for four-Action proofs. On an Apple M4 with ten workers, one-Action
execution improved by 0.127 ms while four-Action execution was neutral. Proof
bytes, retained proving-key memory, and public APIs are unchanged.
