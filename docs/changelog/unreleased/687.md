## zakura-pasta-curves

### Added

- Added `CurveExt::try_prepare_fixed_base_sum` and the `PreparedFixedBaseSum`
  trait, behind the `glv` feature: a doubling-free table for sums over a few
  fixed bases. The Pasta curves implement it with signed 6-bit windows over GLV
  half-scalars, about 44 KiB per base. It runs in variable time, so its scalars
  must be public
  ([#687](https://github.com/zakura-core/common/pull/687)).

## zakura-halo2-proofs

### Changed

- `BatchVerifier::finalize` commits Orchard-shaped instance columns (seven
  full-width rows, then three Boolean flags) through a doubling-free GLV table,
  making that step about 1.2–1.3× faster. The table, about 308 KiB, is built on
  first use and shared by clones of the `Params`. Other instance shapes keep
  the existing path, and results are unchanged
  ([#687](https://github.com/zakura-core/common/pull/687)).
