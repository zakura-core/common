## zakura-protocol

### Added

- `SPHINCS_KEY_COMMITMENT_DOMAIN` (`Zcash/SPHINCS/key/v1`), the domain for
  committing to a leanSphincs public key in a post-quantum account key set
  ([#648](https://github.com/zakura-core/common/pull/648)).

## zakura-transparent

### Changed

- Experimental post-quantum accounts now sign with leanSphincs (SHA-256, tree
  height 22, pruned to a kept subtree of height 10) instead of WOTS+. A spend
  carries the 32-byte public key and the 4,212-byte signature, so the control
  input script signature grows to 4,337 bytes, and account addresses and
  key-set roots change. WOTS+ remains available as `pq::WotsPlus`
  ([#648](https://github.com/zakura-core/common/pull/648)).
