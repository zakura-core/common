## zakura-udon

### Added

- Added `Point::batch_from_bytes`, decoding batches of compressed point
  encodings with interleaved square-root chains while accepting and rejecting
  exactly what `Point::from_bytes` does
  ([#725](https://github.com/zakura-core/common/pull/725)).

## zakura-sensei

### Changed

- Sped up batch verification: proof points decode together ahead of transcript
  reading, instance commitments walk doubling-free fixed-base tables (about
  245 KiB prepared at warmup) with a bundle's shared anchor term computed once,
  and RedPallas batch verification decodes its points together and runs its
  equation on the worker pool for larger batches
  ([#725](https://github.com/zakura-core/common/pull/725)).

## zakura-orchard

### Changed

- Batch validation with the Sensei backend now normalizes every bundle's value
  commitments together with the binding keys and encodes statements across the
  thread pool ([#725](https://github.com/zakura-core/common/pull/725)).
