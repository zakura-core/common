## zakura-orchard

### Added

- Added `bundle::SignatureDigests`, which gives the digest each signature of a
  bundle signs. A `[u8; 32]` implements it for bundles whose signatures share
  one digest; a ZIP 248 v7 transaction gives each signature its own
  ([#753](https://github.com/zakura-core/common/pull/753)).

### Changed

- Changed `Bundle::prepare`, `Bundle::apply_signatures`, and
  `BatchValidator::add_bundle` to take any `bundle::SignatureDigests` instead
  of a `[u8; 32]` sighash, and `Bundle::sign` and `Bundle::append_signatures`
  to use each action's own digest. Callers that pass a `[u8; 32]` keep their
  behaviour; a sighash produced with `.into()` now needs its type stated.
  `BatchValidator::add_bundle` returns the new
  `BatchError::MissingSignatureDigest` for digests that do not cover every
  action. `Bundle::prepare` now returns a `Result`. Both signing entry points
  return `BuildError::MissingSignatureDigest { index }` for the first missing
  action digest. The PCZT roles still sign one shared digest, so they do not
  support v7 transactions yet
  ([#753](https://github.com/zakura-core/common/pull/753)).

## zakura-sapling-crypto

### Added

- Added `bundle::SignatureDigests`, which gives the digest each signature of a
  bundle signs. A `[u8; 32]` implements it for bundles whose signatures share
  one digest; a ZIP 248 v7 transaction gives each signature its own
  ([#753](https://github.com/zakura-core/common/pull/753)).

### Changed

- Changed `Bundle::prepare`, `Bundle::apply_signatures`, and
  `BatchValidator::check_bundle` to take any `bundle::SignatureDigests`
  instead of a `[u8; 32]` sighash, and `Bundle::sign` and
  `Bundle::append_signatures` to use each spend's own digest. Callers that pass
  a `[u8; 32]` keep their behaviour; a sighash produced with `.into()` now needs
  its type stated. `BatchValidator::check_bundle` returns `false` for digests
  that do not cover every spend. `Bundle::prepare` now returns a `Result`. Both
  signing entry points return `Error::MissingSignatureDigest { index }` for the
  first missing spend digest. The PCZT roles still sign one shared digest,
  so they do not support v7
  transactions yet ([#753](https://github.com/zakura-core/common/pull/753)).

## zakura-primitives

### Added

- Added `sighash::V7ShieldedSighashes`, the signature digests of one Sapling,
  Orchard, or Ironwood bundle of a v7 transaction, to pass to that bundle's
  builder or batch validator. Prepare the transaction once with
  `V7SignatureHashes::new`, then call `shielded_sighashes` for each pool.
  The method returns `SighashError::MissingBundle` if the
  transaction has no such bundle
  ([#753](https://github.com/zakura-core/common/pull/753)).
