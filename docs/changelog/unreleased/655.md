## zakura-transparent

### Added

- Add optional `pq` support for SLH-DSA-SHA2-128f and SLH-DSA-SHA2-192s
  signing, verification and native transparent outputs with an output-wide
  parameter version ([#655](https://github.com/zakura-core/common/pull/655)).

## zakura-zcash-script

### Added

- Add optional `pq` signature operations, bounded native argument execution
  and explicit native signature-operation accounting while preserving legacy
  execution rules ([#655](https://github.com/zakura-core/common/pull/655)).

## zakura-primitives

### Added

- Add a `pq` feature forwarding native transparent authorization support
  ([#655](https://github.com/zakura-core/common/pull/655)).
