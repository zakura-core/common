## zakura-orchard

### Removed

- Removed `memuse::DynamicUsage` implementations for bundles, actions, proofs, nullifiers, rho values, note-encryption domains and prepared incoming viewing keys. Code that measured these types with `dynamic_usage()` no longer compiles and must estimate sizes itself
  ([#589](https://github.com/zakura-core/common/pull/589)).
- Removed the unreleased `memory-usage` feature, the `memuse` dependency, and the `group/wnaf-memuse` selection. Manifests that select `memory-usage` must drop it
  ([#589](https://github.com/zakura-core/common/pull/589)).
