## zakura-orchard

### Removed

- Removed `memuse::DynamicUsage` implementations for bundles, actions, proofs, nullifiers, rho values, note-encryption domains and prepared incoming viewing keys, and the `memuse` dependency. Code that measured these types with `dynamic_usage()` no longer compiles and must estimate sizes itself. The `std` feature no longer enables `group/wnaf-memuse`
  ([#589](https://github.com/zakura-core/common/pull/589)).

## zakura-sapling-crypto

### Removed

- Removed `memuse::DynamicUsage` implementations for bundles, spend and output descriptions, compact outputs, `SaplingDomain` and prepared incoming viewing keys, and the `memuse` dependency. Code that measured these types with `dynamic_usage()` no longer compiles and must estimate sizes itself. The `std` feature no longer enables `group/wnaf-memuse`
  ([#589](https://github.com/zakura-core/common/pull/589)).

## zakura-primitives

### Removed

- Removed the `memuse::DynamicUsage` implementation for `BlockHash` and the `memuse` dependency. Code that measured it with `dynamic_usage()` no longer compiles
  ([#589](https://github.com/zakura-core/common/pull/589)).

## zakura-protocol

### Removed

- Removed `memuse::DynamicUsage` implementations for `TxId`, `BlockHeight`, `TxIndex`, `ZatBalance` and the network and upgrade types. The `std` feature no longer enables the `memuse` dependency. Code that measured these types with `dynamic_usage()` no longer compiles
  ([#589](https://github.com/zakura-core/common/pull/589)).
