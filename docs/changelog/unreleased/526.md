## zakura-pasta-curves

### Fixed

- Fixed automatic x86-64 assembly selection to require both ADX and BMI2 in
  Rust's configured target features instead of detecting the build CPU.
  Implicit native and explicit same-triple baseline builds now use the
  portable field backend. Native acceleration remains available with
  `-C target-cpu=native` on a supporting CPU, explicit ADX+BMI2 target features,
  or the existing `x86_64-asm` feature; `portable` still disables this backend
  ([#526](https://github.com/zakura-core/common/pull/526)).
