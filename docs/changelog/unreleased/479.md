Reuse retained sparse permutation-difference commitment bases in the
single-circuit parallel-set path. Across 160 paired cold one-Action Orchard
proofs with ten workers on Apple M4, permutation commitment latency fell from
2.120 ms to 1.528 ms and complete proofs from 43.546 ms to 42.867 ms.
Six-worker x86-64 Linux proofs with the assembly backend fell from 92.737 ms to
91.537 ms. Key generation, proving-key preparation, retained memory, proof
bytes, and public APIs are unchanged.
