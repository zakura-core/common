## zakura-orchard

### Changed

- Sped up spend authorizing key derivation by about a third on average,
  Orchard bundle signing by about half per spend, `append_signatures` by one
  scalar multiplication per action, and nullifier derivation with the
  `backend-halo2` feature by about 7%
  ([#680](https://github.com/zakura-core/common/pull/680)).

## zakura-reddsa

### Added

- Added `SigningKey::negate` and
  `SigningKey::randomize_with_verification_key`, which reuse the stored
  verification key instead of recomputing it
  ([#680](https://github.com/zakura-core/common/pull/680)).

## zakura-sensei

### Added

- Added `redpallas::SigningKey::negate` and
  `redpallas::SigningKey::randomize_with_verification_key`, which reuse the
  stored verification key instead of recomputing it
  ([#680](https://github.com/zakura-core/common/pull/680)).
