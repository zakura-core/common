## zakura-keys

### Added

- Added a `zeroize` feature, enabled by default, that erases the Sapling and
  Orchard spending keys held by `UnifiedSpendingKey` when it is dropped
  ([#633](https://github.com/zakura-core/common/pull/633)).

### Changed

- `UnifiedSpendingKey::to_bytes` (behind `unstable`) now returns
  `secrecy::SecretVec<u8>`; read the bytes with `ExposeSecret::expose_secret`
  ([#633](https://github.com/zakura-core/common/pull/633)).

## zakura-orchard

### Added

- Added a `zeroize` feature that implements `zeroize::Zeroize` for
  `keys::SpendingKey` ([#633](https://github.com/zakura-core/common/pull/633)).

### Changed

- `keys::SpendingKey`'s `Debug` output no longer prints the key bytes
  ([#633](https://github.com/zakura-core/common/pull/633)).

## zakura-sapling-crypto

### Added

- Added a `zeroize` feature that implements `zeroize::Zeroize` for
  `keys::SpendAuthorizingKey`, `keys::ExpandedSpendingKey`,
  `keys::OutgoingViewingKey`, `zip32::DiversifierKey`, and
  `zip32::ExtendedSpendingKey`. The ZIP 32 chain code is not erased
  ([#633](https://github.com/zakura-core/common/pull/633)).

## zakura-reddsa

### Added

- Added a `zeroize-signing-key` feature that implements `zeroize::Zeroize`
  for `SigningKey`, erasing the secret scalar ([#633](https://github.com/zakura-core/common/pull/633)).

## zakura-redjubjub

### Added

- Added a `zeroize` feature that implements `zeroize::Zeroize` for
  `SigningKey` ([#633](https://github.com/zakura-core/common/pull/633)).

## zakura-jubjub

### Added

- Added a `zeroize` feature that implements `zeroize::DefaultIsZeroes` for
  `Fr` ([#633](https://github.com/zakura-core/common/pull/633)).

## zakura-pasta-curves

### Added

- Added a `zeroize` feature that implements `zeroize::DefaultIsZeroes` for
  `Fp` and `Fq` ([#633](https://github.com/zakura-core/common/pull/633)).
