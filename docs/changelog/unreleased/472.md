Reuse one quotient-evaluator workspace per Rayon worker while retaining the
existing scheduling granularity. At `k = 11`, this avoids zero-initializing
16,512,768 bytes for one-Action proofs and 51,831,744 bytes for four-Action
proofs. The four-Action evaluator improved by 0.258 ms on an Apple M4 with ten
workers and by 0.699 ms on x86-64 Linux with six workers. Proof bytes, retained
proving-key memory, and public APIs are unchanged.
