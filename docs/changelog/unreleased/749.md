## zakura-udon

### Changed

- Changed x86-64 builds that enable AVX2, and builds that force the x86-64
  backend with `x86_64-asm`, to decode batches of points and to sum buckets of
  points with AVX2. The `x86_64-asm` feature now requires a CPU with AVX2 as
  well as BMI2 and ADX; `portable` still disables all of it
  ([#749](https://github.com/zakura-core/common/pull/749)).

### Fixed

- Fixed a build failure ("inline assembly requires more registers than
  available") of the x86-64 backend when a dependent crate is built with thin
  LTO and one codegen unit
  ([#749](https://github.com/zakura-core/common/pull/749)).

## zakura-sensei

### Changed

- Changed Orchard instance commitments to be summed jointly from wider
  fixed-base tables. Verification accepts and rejects exactly what it did; the
  verifier's warm-up tables grow from about 245 KiB to about 1.2 MiB
  ([#749](https://github.com/zakura-core/common/pull/749)).
