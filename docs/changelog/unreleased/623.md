## zakura-primitives

### Added

- Added `transaction::sighash::PrecomputedSighashData`, which hashes the data that
  all signature hashes of a transaction share once, and then computes the
  signature hash of each input without rehashing the other inputs and outputs.
  `PrecomputedSighashData::new_zip244` accepts version 5 and later transactions
  without Sapling proofs and returns the new `transaction::sighash::Zip244Error`
  for earlier versions
  ([#623](https://github.com/zakura-core/common/pull/623)).

### Changed

- The transaction builder computes transparent and shielded signature hashes
  through `PrecomputedSighashData`, so signing a transaction with many
  transparent inputs no longer takes time quadratic in the number of inputs.
  Signature hashes are unchanged
  ([#623](https://github.com/zakura-core/common/pull/623)).
