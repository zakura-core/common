## zakura-transparent

### Added

- Added opt-in SLH-DSA-SHA2-128f and SLH-DSA-SHA2-192s key generation, signing,
  and verification through the `pq` feature. P2SH redeem-script versions 1 and 2
  select these parameter sets and their signing contexts after commitment
  authentication, while sharing existing script operations and multisig rules.
  Callers supply a trusted previous output and transaction checker; these APIs
  do not activate PQ outputs
  ([#650](https://github.com/zakura-core/common/pull/650)).

## zakura-zcash-script

### Added

- Added a raw-signature checking hook that preserves ECDSA behavior by default,
  and an opt-in `pq` evaluator with bounds for larger serialized arguments and
  stack payloads ([#650](https://github.com/zakura-core/common/pull/650)).

## zakura-primitives

### Added

- Added a `pq` feature that enables the transparent PQ signature and script APIs
  ([#650](https://github.com/zakura-core/common/pull/650)).
