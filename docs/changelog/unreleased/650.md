## zakura-transparent

### Added

- Added opt-in SLH-DSA-SHA2-192s key generation, signing, and verification through
  the `pq` feature, including script execution with at most one signature
  verification attempt. Callers must authenticate the spending script and supply
  its transaction digest and signing context; this does not activate PQ outputs
  ([#650](https://github.com/zakura-core/common/pull/650)).

## zakura-zcash-script

### Added

- Added a raw-signature checking hook that preserves ECDSA behavior by default,
  and an opt-in `pq` evaluator with bounds for larger serialized arguments and
  stack payloads ([#650](https://github.com/zakura-core/common/pull/650)).

## zakura-primitives

### Added

- Added a `pq` feature that enables the transparent PQ signature and script APIs
  ([#650](https://github.com/zakura-core/common/pull/650)).
