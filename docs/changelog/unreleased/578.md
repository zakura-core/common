## zakura-halo2-proofs

### Fixed

- `dev::circuit_dot_graph` now writes tabs, control characters and combining
  marks in namespace names as-is instead of as Rust escape sequences that
  Graphviz displayed literally
  ([#578](https://github.com/zakura-core/common/pull/578)).

### Removed

- Removed the `tabbycat` dependency and its implicit Cargo feature; the
  `dev-graph` feature now renders DOT output directly
  ([#578](https://github.com/zakura-core/common/pull/578)).
