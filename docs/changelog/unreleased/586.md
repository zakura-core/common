## zakura-equihash

### Changed

- Standard-library builds use `std::io` directly. Builds without the standard
  library must enable the new `no-std-io` feature, which selects the optional
  `corez` I/O implementation and forwards that selection to Common dependencies.
  The serialization format is unchanged
  ([#586](https://github.com/zakura-core/common/pull/586)).
