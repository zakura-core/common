## zakura-protocol

### Added

- Added the experimental WOTS key-commitment domain constant using the neutral
  `Zcash/WOTS/key/v1` protocol namespace
  ([#639](https://github.com/zakura-core/common/pull/639)).

## zakura-transparent

### Added

- Added an opt-in WOTS-only P2SH construction and verification API for
  disposable-key regtest experiments, reconstructing the public key from the
  signature and public seed instead of transmitting its endpoints
  ([#639](https://github.com/zakura-core/common/pull/639)).

## zakura-zcash-script

### Added

- Added an experimental `experimental-wots` feature with a `CHECKWOTS`
  instruction (opcode `0xba`). It runs only when the caller also sets
  `Flags::CHECKWOTS` and implements `SignatureChecker::check_wots`; the default
  checker rejects every authorization. The instruction reassembles five
  signature chunks and hands them, the public seed and the expected key
  commitment to the caller's checker
  ([#639](https://github.com/zakura-core/common/pull/639)).
