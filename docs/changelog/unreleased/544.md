## zakura-reddsa

### Removed

- Removed the `frost` feature and `reddsa::frost` module in version 3.0.0.
  FROST users must depend on `zakura-reddsa-frost` and import
  `reddsa_frost::{redjubjub, redpallas}` instead
  ([#544](https://github.com/zakura-core/common/pull/544)).

## zakura-reddsa-frost

### Added

- Added a separate crate for RedJubjub and RedPallas FROST threshold signatures,
  including key generation, signing, and rerandomization APIs moved from
  `reddsa::frost` ([#544](https://github.com/zakura-core/common/pull/544)).
