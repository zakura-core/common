This PR only changes private rational-advice prover bookkeeping. A contiguous
slot layout removes ten allocations per Orchard circuit and replaces per-cell
division and remainder with power-of-two index decoding, reducing the measured
rational-advice phase by 7–8 microseconds on Apple M4 and 11–26 microseconds on
x86-64 Linux without changing proofs or API.
