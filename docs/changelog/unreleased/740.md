## zakura-transparent

### Added

- Added `sighash::SighashPolicy`, the set of sighash types a PCZT role
  accepts, and `pczt::Input::{sign_with_sighash_policy,
  append_signature_with_sighash_policy,
  with_signable_input_with_sighash_policy}` and
  `pczt::Bundle::finalize_spends_with_sighash_policy`, which take one
  ([#740](https://github.com/zakura-core/common/pull/740)).

### Changed

- Changed `pczt::Input::{sign, append_signature}` to check that the input's
  `redeem_script` is the script its `script_pubkey` commits to, and to sign
  only for `SighashType::ALL`. Use the `_with_sighash_policy` variants to
  permit other sighash types
  ([#740](https://github.com/zakura-core/common/pull/740)).
- Changed `pczt::Input::with_signable_input` to apply the same checks and
  return `Result<T, SignerError>` instead of `T`
  ([#740](https://github.com/zakura-core/common/pull/740)).
- Changed `pczt::Bundle::finalize_spends` to require every partial signature
  it uses to end in a sighash-type byte matching its input's `sighash_type`,
  and to finalize only `SighashType::ALL` signatures. Signatures that are
  discarded are not checked
  ([#740](https://github.com/zakura-core/common/pull/740)).
- Added the `DisallowedSighashType` and `InvalidInput` variants to
  `pczt::SignerError`, and the `DisallowedSighashType` and
  `MismatchedSighashType` variants to `pczt::SpendFinalizerError`
  ([#740](https://github.com/zakura-core/common/pull/740)).

### Fixed

- Fixed `pczt::Bundle::finalize_spends` to return
  `SpendFinalizerError::InvalidSignature` for a P2PKH partial signature too
  large for a script push, instead of panicking
  ([#740](https://github.com/zakura-core/common/pull/740)).
