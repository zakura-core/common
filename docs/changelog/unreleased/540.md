## zakura-protocol

### Added

- Added `zcash_protocol::encoding` with `MAX_COMPACT_SIZE`, `CompactSize`,
  `Vector`, `Array`, `Optional`, and `ReverseHex`, preserving the
  `zcash_encoding 0.4.0` API and serialization behavior, including writing
  values above the reader's maximum
  ([#540](https://github.com/zakura-core/common/pull/540)).

## zakura-note-encryption

### Added

- Added the complete `zcash_note_encryption 0.4.2` implementation as the
  `zakura-note-encryption` package, retaining the `zcash_note_encryption`
  library target, note-encryption and recovery APIs, features, and no-std
  support. The package inherits Common's edition 2024 and MSRV 1.91
  ([#540](https://github.com/zakura-core/common/pull/540)).

## zakura-orchard

### Changed

- Changed note-encryption aliases, byte-wrapper signatures, and Domain,
  BatchDomain, and ShieldedOutput implementations to use
  `zakura-note-encryption`. Existing import spelling is preserved, but
  upstream and fork traits and types are not interchangeable
  ([#540](https://github.com/zakura-core/common/pull/540)).

## zakura-sapling-crypto

### Changed

- Changed public note-encryption, compact-output, output-description, and
  recovery signatures and trait implementations to the
  `zakura-note-encryption` type family. Upstream byte wrappers and traits
  cannot be mixed with the fork
  ([#540](https://github.com/zakura-core/common/pull/540)).

## zakura-primitives

### Changed

- Changed the note-encryption dependency family exposed through Sapling and
  Orchard transaction/builder types to `zakura-note-encryption`, retaining
  allocation and pre-ZIP-212 support
  ([#540](https://github.com/zakura-core/common/pull/540)).
