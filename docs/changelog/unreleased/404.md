## zakura-pasta-curves

### Added

- Added the opt-in `accelerator` feature: `glv::accelerator` is a write-once,
  process-wide registry for an external `MultiexpAccelerator` (such as a GPU
  backend) that the GLV MSM planner consults before its CPU backends, so any
  MSM reaching `CurveExt::try_multiexp_vartime` with at least the backend's
  `min_terms` terms is offered to it first and falls back to the CPU planner
  when it declines ([#404](https://github.com/zakura-core/common/pull/404)).

## zakura-pasta-msm-metal

### Added

- Added the crate: an experimental Apple GPU (Metal) multiscalar
  multiplication backend for the Pasta curves, installed process-wide through
  `pasta_msm_metal::install`, with a CPU `Reference` backend of the same
  pipeline for every platform. The Metal backend is unbenchmarked and
  nothing installs it by default
  ([#404](https://github.com/zakura-core/common/pull/404)).
