## zakura-pasta-curves

### Added

- Added `PreparedZeroCheck::estimate_scalar_work_vartime`, an optional additive
  backend-defined estimate for comparing arbitrary scalar samples through the
  same prepared handle. Pasta's prepared backend estimates its actual main and
  residual-tail digit placements
  ([#328](https://github.com/zakura-core/common/pull/328)).

## zakura-halo2-proofs

### Changed

- Reused prepared `k = 11` advice commitments across batched circuit proofs in
  `multicore` builds without `orbits` when a stratified count sample finds a
  sparse per-circuit witness delta and an aggregate prepared-backend sample
  predicts no scalar-work regression. Per-column count guards and a sampled
  magnitude guard reject measured adverse profiles. Proof format, RNG
  consumption, and verification are unchanged.
  This routing is variable-time and can expose witness similarity through
  proving latency, as documented by the affected proving APIs
  ([#328](https://github.com/zakura-core/common/pull/328)).
